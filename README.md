# PARTS GARAGE

Адаптивный демонстрационный сайт магазина автозапчастей под заказ.

## Публикация на GitHub Pages

1. Открой **Settings → Pages**.
2. В разделе **Build and deployment** выбери `Deploy from a branch`.
3. Выбери ветку `main`, папку `/(root)` и нажми **Save**.
4. Сайт: https://egorfateew-ops.github.io/parts-garage/

## Возможности демо

- Каталог с категориями, поиском и сортировкой.
- Карточки товаров с описаниями и артикулами.
- Избранное и корзина с изменением количества.
- Расшифровка VIN через бесплатный NHTSA vPIC API.
- Отображение марки, модели, года, кузова и доступных характеристик.
- Передача VIN и найденных данных автомобиля в заявку на подбор.
- Выбор группы деталей для заявки.
- Демонстрационное оформление заказа и отслеживание статуса.
- Демо-панель администратора.
- Адаптивная мобильная версия.

## Ограничения VIN-поиска

VIN расшифровывается через NHTSA vPIC: https://vpic.nhtsa.dot.gov/api/

База рассчитана прежде всего на автомобили 1981 года выпуска и новее, предназначенные для продажи или импорта в США. Для автомобилей других рынков ответ может быть неполным или отсутствовать. Сервис также ограничивает частоту запросов.

Расшифровка VIN определяет базовые характеристики автомобиля, но **не подбирает автоматически OEM-артикулы и не подтверждает совместимость конкретной детали**. Для этого потребуется подключить коммерческий каталог запчастей (например, TecDoc или API поставщика) и серверную часть магазина.

## Важно

Это frontend-прототип на HTML, CSS и JavaScript. Корзина, избранное, заявки и заказы хранятся в `localStorage` конкретного браузера.

Реальные заявки не отправляются менеджеру, а пользователи не видят данные друг друга. Нет backend, базы данных, полноценной авторизации, онлайн-оплаты и интеграции с каталогом поставщиков.

Телефон, отзывы, сроки и товары на странице — демонстрационные данные. Перед коммерческим запуском замени их на реальные.
