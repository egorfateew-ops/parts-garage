# PARTS GARAGE

Адаптивный демонстрационный сайт магазина автозапчастей под заказ.

## Публикация на GitHub Pages

1. Открой репозиторий **Settings → Pages**.
2. В разделе **Build and deployment** выбери **Deploy from a branch**.
3. В поле **Branch** выбери `main`, папку `/(root)` и нажми **Save**.
4. После публикации сайт будет доступен по адресу:

   https://egorfateew-ops.github.io/parts-garage/

## Возможности демо

- Каталог с категориями, поиском и сортировкой.
- Карточки товаров с описаниями и артикулами.
- Избранное и корзина с изменением количества.
- Подбор по марке и модели автомобиля.
- Форма заявки по VIN и названию детали.
- Демонстрационное оформление заказа и отслеживание статуса.
- Личный кабинет и демо-панель администратора.
- Адаптивная мобильная версия.

## Важно

Это frontend-прототип на HTML, CSS и JavaScript. Данные корзины, избранного, заявок и заказов хранятся в `localStorage` конкретного браузера.

Реальные заказы не отправляются менеджеру, а пользователи не видят данные друг друга. Нет backend, базы данных, авторизации, онлайн-оплаты и реального VIN API. Для запуска полноценного магазина эти сервисы нужно подключить отдельно.

Телефон, отзывы, сроки и товары на странице — демонстрационные данные. Перед коммерческим запуском замени их на реальные.
